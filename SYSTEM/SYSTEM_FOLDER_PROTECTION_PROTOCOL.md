# BA2-V1 — SYSTEM FOLDER PROTECTION

SYSTEM/ is a protected BA2-V1 system area.

- Chat-requested GitHub operations must never remove SYSTEM/ or any file inside it.
- Project clearing, reset, archive, or recreation operations are strictly limited to PROJECTS/.
- No repository-wide destructive operation may be used for project management.
- Permanent removal of SYSTEM/ or its files is manual-only by the user through GitHub.
- System files may still receive authorized maintenance updates.
- Before any destructive project operation, verify that every target path is inside PROJECTS/ and that SYSTEM/ is untouched.
- If scope is ambiguous, stop rather than write to GitHub.

This protection is permanent unless the user manually changes the system files through GitHub.
